# 확장 문법 {#extended}

==중요한 내용==과 ==**굵은 하이라이트**==를 함께 쓸 수 있습니다.

## 용어와 정의 {#definitions}

공유 문서
: 여러 사용자가 함께 편집하는 문서입니다.
: ==각 사용자의 변경==을 병합합니다.

원문
: Markdown 표기를 보존합니다.

## 코드 색상

```json
{
  "title": "한글 문서",
  "collaboration": true,
  "version": 2
}
```

## 기존 확장 기능

| 항목 | 상태 |
| :--- | :---: |
| ==하이라이트== | 지원 |
| ~~취소선~~ | 지원 |

- [x] 표와 작업 목록
- [x] 사용자 지정 제목 ID

각주도 사용할 수 있습니다.[^note]

[^note]: 각주의 내용은 문서 안에 보존됩니다.
