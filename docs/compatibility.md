# 호환성과 검증 범위

이 문서는 목표 요구사항과 구분한 현재 개발 버전의 상태다. 자체 fixture 통과가 전체 GFM 적합성 인증을 뜻하지 않는다.

## 문법

| 영역 | 구현한 범위 |
| --- | --- |
| 기본 블록 | ATX/setext 제목, 문단·빈 줄, soft/hard break, 수평선, 인용문 |
| 목록 | 순서·비순서·작업 목록, 단계별 들여쓰기, Enter·Tab·내어쓰기 |
| 인라인 | 굵게·기울임·중첩 조합·취소선·하이라이트·이스케이프·인라인 코드 |
| 코드 | fence·언어 이름·일반 들여쓰기 코드, 코드 원문 보호, 선택적 줄 번호·기본 어휘 색상 |
| 링크 | 일반/상대/섹션, 균형 괄호 URL, 참조 링크, http/https/www·이메일 autolink, 제목·사용자 앵커·`{#custom-id}` |
| 표 | 헤더·정렬·셀 원문·br, Tab 새 행, 행/열 도구·드래그 선택·표 밖 이동 |
| 확장 | 각주·반복 참조·다문단 정의·최초 참조 번호, 다섯 알림 유형, 정의 목록(dl/dt/dd), 접기 |
| HTML | br/mark/sub/sup/ins/a(name)/picture/source/img/details/summary, 주석, 속성·URL 허용 목록 |
| 메타데이터 | YAML 원문 보존·직접 편집, 최상위 단순 layout 문자열 읽기 |
| 이모지 | 프로젝트 자체 Unicode 대응표 12개 |

이모지 별칭은 `:smile:`, `:+1:`, `:thumbsup:`, `:heart:`, `:warning:`, `:check:`, `:rocket:`, `:tada:`, `:fire:`, `:eyes:`, `:tent:`, `:joy:`다. 미지원 별칭은 원문을 유지한다. 코드·주석·Front Matter에서는 변환하지 않는다.

HTML 문자 참조는 길이 규칙을 검증한 숫자형과 세미콜론으로 끝나는 HTML 이름 문자 참조 표를 읽는다. 이름 표는 Python 표준 라이브러리 html.entities의 데이터에서 생성해 Rust 상수로 포함하며 런타임 의존성을 추가하지 않는다. 미지원 태그와 구문은 실행하지 않고 원문으로 표시·보존한다. 닫히지 않은 Front Matter는 일반 원문으로 취급한다.

복잡한 구분자 결합, 중첩 컨테이너·여러 문단 목록, 불규칙 표의 암시적 셀, 여러 줄 참조 정의 등의 전체 표준 규칙은 아직 적합성 corpus로 검증하지 않았다. 현재 파서는 완전한 CommonMark/GFM 구현으로 인증하지 않았다. 이런 문서의 의미를 다른 렌더러와 동일하다고 보장하지 않는다. 내보내기 정규화는 굵게·들여쓰기·줄바꿈·이모지 등 구현한 규칙에 제한하며 모든 대체 문법을 하나의 canonical 표기로 완전히 통합하지는 않는다.

## 편집과 보존

원문은 Rust가 보유하며 미허용 HTML 속성도 남긴다. 브라우저 DOM에는 허용된 요소·속성만 출력한다. 붙여넣기는 허용 구조로 변환하므로 임의 글자 크기·셀 음영 등이 편집 속성으로 유입되지 않는다. 병합 셀은 좌측 상단에 내용, 나머지 빈 셀로 펼치고 셀 다문단은 br로 합친다. 중첩 표는 텍스트화한다. 일반 텍스트의 탭은 공백으로 바꾸며 Markdown은 해석한다.

문법 노출·원본 화면 전환은 history를 바꾸지 않는다. 숨겨진 링크 목적지·구분자 위치도 유지한다. 자동 닫기 추적과 변환 undo/redo, 원문·리치의 공동 history를 테스트한다. 지금의 history는 최대 200개 트랜잭션이며 시간 기반 타이핑 묶음은 아직 하지 않는다.

첨부는 Base64 data URL과 URI 인코딩 파일명을 포함한 Markdown 링크로 저장한다. 다운로드 시 Blob URL을 생성하고 사용 후 해제한다. 인라인 SVG를 허용하지 않으며 일반 첨부로 다운로드한다. 외부 저장소는 현재 구현 범위 밖이다.

## 실행 환경

브라우저 자동 수용 테스트는 로컬 in-app 브라우저에서 수행했다. 노출된 UA는 Chrome/155.0.0.0 (macOS)이다. 별도 Chrome·Edge·Firefox·Safari 전체 조합이나 Android/iOS 실기기를 모두 시험한 것은 아니다. Safari 네이티브 앱 자동화 연결 시도는 시간 초과로 테스트를 실행하지 못했다.

합성 `beforeinput`·composition 이벤트, grapheme 경계, 커서 투영·복원, 표·붙여넣기·첨부·읽기 전용·대화상자·다중 인스턴스의 테스트 페이지를 제공한다. macOS 두벌식은 Firefox에서 실제 앱 키 입력으로 리치·전체 원본 화면의 조합 중 원격 삽입과 commit을 확인했다. 다른 OS/브라우저의 입력기, 모바일 가상 키보드·터치 드래그·스크린 리더 음성 출력은 별도 수동 검증이 필요하다.

모바일 UI의 가로 툴바·표 스크롤·명시적 링크 열기·선택 기억·visualViewport 대응을 구현했다. 키보드 명령 팔레트·표 위치 라벨·포커스 표시·대화상자 복귀를 제공하지만 접근성 적합성 수준을 인증한 것은 아니다.

브라우저는 WebAssembly, Shadow DOM, ES modules, BigInt, Intl.Segmenter, dialog, VisualViewport(있을 때), CSS :has를 지원하는 현대 환경을 대상으로 한다. 정확한 최소 버전 정책은 아직 정하지 않았다.

## 성능과 다음 검증

`node scripts/check_wasm.mjs docs/performance.json`으로 같은 WASM 바이너리를 측정한다. 저장된 결과는 해당 런타임의 한 번 측정이며 SLA가 아니다. DOM 레이아웃·페인트·클립보드 앱·모바일 메모리는 포함하지 않는다.

전체 요구사항 완료를 위해 남은 항목은 전체 문법 fixture와 canonical 정규화 보강, 증분 파싱·DOM 좌표 패치 최적화, 대상 브라우저/모바일/실제 IME/스크린 리더 검증이다. 현재 구현은 로컬에서 사용할 수 있는 개발 버전이며 이 검증을 마친 최종 릴리스는 아니다.

## 확장 문법 추가 범위

하이라이트 `==내용==`은 한 줄 안에서 지원한다. 툴바·명령 팔레트, 자동 닫기, 모드별 노출과 자동 변환 undo에도 적용했다. 새 위/아래 첨자 Markdown 문법은 사용자 요청으로 지원하지 않으며 `H~2~O`, `X^2^`는 일반 텍스트다. 기존 HTML sub/sup 처리는 유지한다.

제목 ID는 유효한 마지막 `{#id}` 접미사만 인식하며 잘못된 접미사는 표시·보존한다. 중복 ID에는 순서대로 숫자 접미사를 붙인다. 정의 목록은 여러 용어·여러 정의·4칸 연속 줄을 지원한다. 복잡한 중첩 블록과 빈 줄을 포함한 정의의 완전한 외부 방언 적합성을 보장하지 않는다.

코드 색상 지원 언어명은 json, rust/rs, javascript/js, typescript/ts, python/py, bash/sh/shell, css, html/xml이다. 문자열·숫자·리터럴과 주요 스크립트 언어의 키워드·주석에 기본 색상을 적용한다. CSS/HTML/XML은 문자열·숫자 위주의 제한적 표시다. 정규식 리터럴·템플릿 보간·중첩 주석·Python 삼중 문자열 등은 완전하게 분석하지 않는다. 미지원 언어의 코드도 원문과 언어 이름을 유지한다.

이는 기존 단일 사용자 에디터와 협업 snapshot 렌더러가 공유하는 파서에 적용된다. 협업 리치 UI 전체 통합의 완료 여부와는 별도다.

## 전체 예제 및 협업 화면 검증

공식 GFM 672개 전체 예제의 구조 비교는 현재 262개 일치, 410개 불일치다. 안전 정책·별도 확장 차이와 실제 미구현 규칙이 함께 포함된다. 단순 fixture 통과를 전체 적합성으로 표현하지 않는다. 원문과 기대·실제 HTML은 `/gfm-audit.html`에서 확인한다. 기존에 통과하던 예제의 새 회귀는 build 시 실패한다.

공유 리치·하이브리드·Markdown·전체 원본 화면을 연결했다. 표·셀 ID를 유지하는 명령과 원본 문법 투영을 사용하며 불완전 표는 공유되지 않은 초안으로 보존한다. 정확한 지원 경계는 collaboration_api.md, 실제 OS 입력·모바일 viewport·GFM 검사 방법은 [검증 기록](validation.md)에 설명한다. 모바일 실기기·가상 키보드 및 전체 GFM 합격은 아직 남아 있다.
