# 리치 편집의 커서 경계

리치·하이브리드의 편집 명령은 원문 바이트 위치와 화면 텍스트 위치를 구분한다. 화면에서 `굵게` 앞은 원문의 `**` 앞/뒤와 다른 좌표다. DOM의 최근접 위치를 그대로 문자 삭제에 사용하면 숨겨진 기호를 삭제할 수 있다.

## 공통 계산

- `editing_markup()`은 현재 파서 HTML을 기준으로 좌표 트리를 캐시한다. 하이브리드 구문 노출이나 표 핸들·문단 표시 등 라이브 DOM 장식이 이 트리를 바꾸지 않는다.
- `inline_edge()`는 인라인 텍스트의 시작/끝과 여는/닫는 원문 기호의 바깥 경계를 연결한다. 중첩 서식은 바깥쪽 경계를 사용한다.
- `text_caret()`는 본문·제목의 원문 범위와 표시 텍스트의 시작/끝을 함께 제공한다. 원본/Markdown 화면과 범위 선택은 기존 원문 좌표를 유지한다.
- 삭제는 표시 텍스트의 grapheme 또는 문자 참조 단위를 대상으로 삼는다. 기호 사이의 숨겨진 위치로 이동해도 기호 한 글자를 삭제하지 않는다. 내용이 완전히 지워진 인라인 구문은 기호까지 하나의 단위로 제거한다.

## 블록 편집

본문 시작 Backspace와 앞 본문/제목 끝 Delete는 텍스트 블록 사이의 구분 개행을 제거하여 병합한다. 표·목록·인용·코드 등 구조 블록을 가로질러 평문으로 합치지 않는다. 제목으로 시작하는 다음 블록의 문법 전환은 이 병합에 포함하지 않는다.

본문·제목 끝 Enter는 닫힘 기호와 제목 문법을 보존하고 `&nbsp;`가 있는 새 문단을 추가한다. 다음 블록까지의 구분 개행은 새 문단 앞뒤로 배치하며 커서는 그 새 문단에 둔다. 인라인 시작에서 Enter/Shift+Enter는 여는 기호 앞을 사용한다.

브라우저 DOM 선택/UTF-8 좌표 변환 자체는 기존 SDK 계약을 유지한다. 공통 경계 정보는 편집 명령이 어떤 원문 범위를 변경해야 하는지 결정하며 IME 조합 중 DOM을 다시 구성하지 않는다.
