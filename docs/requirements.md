# 요구사항

## 목표와 원칙

임베딩 가능한 독립 OSS 편집기를 만든다. Rust/WASM을 단순 렌더러로 사용하지 않고 문서 트리, 명령, 선택 영역, undo/redo, Markdown 파싱·저장의 기준 상태로 사용한다. 브라우저는 입력·IME·DOM·클립보드·툴바를 담당한다.

- 외부 crate, JavaScript 패키지, 편집기 프레임워크, 외부 YAML 파서 및 외부 이모지 데이터셋을 사용하지 않는다.
- 화면에서 편집 가능한 서식은 지원 Markdown 또는 허용 HTML로 저장할 수 있어야 한다.
- 지원 문법은 의미와 구조를 보존하며 정규화한다. 미지원·미완성 원문, Front Matter, 미허용 HTML 속성은 보존한다.
- 설정 키, 함수·변수·필드는 `snake_case`를 기본으로 한다. Rust 타입·트레이트는 `PascalCase`, 상수는 `SCREAMING_SNAKE_CASE`, 외부 API 이름은 원래 표기를 따른다.

## 편집 모드

| 모드 | 기본 정책 |
| --- | --- |
| `hybrid` | 기본값. 인라인 요소는 커서 접근 시 문법을 노출하고, 표는 구조를 유지하며 직접 편집 |
| `rich` | 커서 위치와 관계없이 리치 표현 유지 |
| `markdown` | 활성 편집 요소의 Markdown 원문 노출 |
| 원본 화면 | 위 세 모드와 별개로 문서 전체 원문을 직접 편집 |

`elements.<element>.reveal_markdown`으로 모드 프리셋을 덮어쓴다. 활성 요소는 hover가 아닌 논리적 커서·선택으로 판단한다. 표현 전환만으로 문서를 변경하거나 undo 항목을 만들지 않는다. 전환 시 선택 방향·커서·스크롤을 유지한다. 조합·터치 드래그 선택 중에는 전환을 미룬다.

제목·목록·인용문은 구조를 유지하며 활성 줄의 문법을 표시한다. 코드 블록은 코드 직접 편집, 각주·접기·알림은 식별자·유형을 편집할 조작을 제공한다. 주석과 Front Matter는 원문 편집 정책을 적용한다.

## 지원 문법

GFM을 기반으로 제목·문단·인용문·수평선·중첩 목록·작업 목록·표·굵게·기울임·중첩 서식·취소선·인라인 코드·코드 블록·링크·이미지·이스케이프를 지원한다. 각주, 알림 블록, Unicode 이모지 별칭, HTML 주석, 허용 HTML, YAML Front Matter도 포함한다. 세부 저장 규칙은 [문법 명세](formatting.md)에 둔다.

## 입력과 편집

- 입력 중 Markdown 문법을 감지해 지원 요소로 자동 변환한다. 미완성 입력을 허용하며 코드·주석·Front Matter에서 본문 변환을 실행하지 않는다.
- 자동 변환 직후 undo는 변환을 취소하고 해당 Markdown 기호를 이스케이프한다. 예: `**텍스트**` → `\*\*텍스트\*\*`. 이 작업의 redo도 제공한다.
- `Enter`는 새 문단, `Shift+Enter`는 강제 줄바꿈을 삽입한다. 표 안 Enter의 상세 규칙은 아직 확정하지 않았다.
- 자동 닫기는 전체·구분자별로 설정한다. 굵게·기울임·취소선·인라인 코드·링크 괄호·HTML 주석을 대상으로 선택 감싸기, 자동 삽입한 닫는 기호 건너뛰기, 빈 쌍 삭제를 지원한다.
- 자동 삽입 기호의 출처를 추적한다. IME 조합·붙여넣기에는 자동 닫기를 적용하지 않으며 코드·주석·Front Matter 문맥을 구분한다.
- 복사 시 편집 보조 UI를 제외하고 일반 복사와 Markdown 복사를 구분한다. 읽기 전용은 같은 모델과 표시 규칙을 사용한다. 변경 상태를 호스트에 알린다.

## 표

하이브리드·리치 모드에서 활성 표의 구조를 유지한다. 다음 다섯 동작은 확정 사항이다.

1. 마지막 셀에서 Tab을 누르면 새 행을 만들고 그 행의 첫 셀로 이동한다.
2. 셀 내부에서는 방향키로 텍스트 커서를 옮기고, 경계에서는 인접 셀로 이동한다.
3. 드래그로 여러 셀·행·열을 선택한다.
4. 행·열 삽입·삭제 메뉴를 제공한다.
5. 키보드와 포인터로 표 밖의 편집 위치로 이동한다.

Tab/Shift+Tab으로 셀을 순회한다. 표 밖 이동 키 조합, 경계 방향키의 세부 판정, 헤더 행 삭제 정책 등은 [미확정 목록](implementation_plan.md)에 둔다. 표의 열 정렬을 보존한다.

## 파일과 이미지

일반 파일은 드롭·파일 선택 시 Base64 `data:` URL 다운로드 링크로 삽입한다. 이미지는 드롭·파일 선택·클립보드 붙여넣기로 Base64 임베딩하고 표시한다. 원래 파일명과 MIME 타입을 보존한다. 첨부 링크는 다운로드로 처리하며 첨부 HTML 등을 편집 문서 안에서 실행하지 않는다.

현재 기본 저장 방식은 `embedded`다. 추후 호스트 저장소가 반환한 URL을 사용하도록 저장소 구현을 편집 코어에서 분리한다. 개별 파일·전체 첨부 용량 제한은 설정 가능하게 하되 숫자 기본값과 파일명 저장 문법은 미확정이다. 큰 첨부 데이터를 undo·매핑마다 복제하지 않는다.

## 레이아웃

CSS로 본문 글꼴·색상·간격·표·코드·알림 등의 표시를 바꿀 수 있고 실행 중 교체 가능해야 한다. 읽기·리치 편집은 본문 스타일을 공유한다. 원본 화면 글꼴은 별도 설정한다. 호스트 스타일과 적용 범위를 격리한다.

적용 순서는 기본 레이아웃 → 인스턴스 설정 → Front Matter의 최상위 `layout` 문자열이다. 값은 호스트에 등록된 레이아웃 이름으로 해석하며 알 수 없거나 해석할 수 없으면 인스턴스 설정으로 돌아간다. 레이아웃 변경 자체는 본문 저장 내용을 바꾸지 않는다.

## 브라우저·모바일·접근성

데스크톱 Chrome·Edge·Firefox·Safari, Android Chrome, iOS/iPadOS Safari와 한글 IME를 지원 대상으로 한다. 지원 버전과 성능 수치는 구현·측정 후 정한다.

- 툴바 사용 시 선택을 기억하고 적용 후 포커스와 커서를 복원한다.
- 모바일 표 도구 메뉴, 표 영역 가로 스크롤, 링크 탭으로 편집 및 별도 열기 조작을 제공한다.
- 모바일 툴바에 강제 줄바꿈·들여쓰기·내어쓰기를 제공하고 가상 키보드에 맞춰 커서·메뉴를 배치한다.
- Tab 우선순위는 표 셀 이동 → 목록 들여쓰기 → 다음 UI 포커스 이동이다. Shift+Tab은 역방향이다. 편집 영역을 빠져나갈 수 있어야 한다.
- 툴바의 모든 기능을 키보드 명령으로 실행할 수 있게 한다. 기본 바인딩은 제목 Ctrl+1~6, 굵게 Ctrl+B, 기울임 Ctrl+I, 링크 Ctrl+K다. 호스트가 재설정할 수 있다. 브라우저 예약 키 충돌을 고려한 대체 바인딩은 추후 확정한다.
- 스크린 리더에 셀 위치·헤더를 전달한다. 자동 변환 안내는 선택 가능한 비시각적 알림으로 제공한다.
- 대화상자·메뉴는 포커스를 관리하고 닫으면 논리적 편집 위치로 복귀한다. 위치는 인스턴스 메모리에 두며 Markdown이나 Front Matter에 저장하지 않는다.
- 기본 레이아웃은 충분한 대비와 명확한 포커스 표시를 제공한다.

## 범위 밖

서비스 종속 멘션·이슈·PR 참조·알림·자동 완성·업로드 서비스 연동, ACL·REST·MCP·페이지 이동·버전 이력, 특정 DB 저장소는 포함하지 않는다. 일반 링크·이미지와 호스트 확장 지점은 유지한다. LaTeX·Mermaid는 추후 별도 WASM 개발 범위다. YAML 전체 검증·구조화 편집·문법 오류에 의한 저장 차단은 포함하지 않는다.

## 확장 문법 범위 갱신 (2026-10-23)

사용자가 지정한 Markdown Guide 확장 문법 페이지를 기준으로 하이라이트·정의 목록·제목 ID·코드 색상과 이모지 예제를 지원한다. 이미 구현한 표·fence·각주·취소선·작업 목록·자동 링크는 유지한다. 후속 사용자 지시에 따라 단일 tilde 아래첨자와 caret 위첨자 Markdown 표기는 제외한다. 자세한 문법·코드 언어·별칭 범위와 호환성 한계는 formatting.md와 compatibility.md를 따른다.
