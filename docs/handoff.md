## 결정 우선순위

최신 사용자 결정 → 이전 사용자 결정 → 채택된 제안 → 미채택 제안 순으로 구분한다. 주석은 최신 결정에 따라 리치 편집에서 회색 원문으로 직접 편집하고 읽기에서 숨긴다. 저장 문법은 지원 구문을 정규화하되 미지원 원문·YAML·미허용 HTML 속성은 보존한다. CSS 표시 설정은 `layout`으로 명명한다. 코드와 설정은 `snake_case`를 따른다.

## 로컬 검증 상태

이전 시점에는 Rust 도구 체인이 없어 검증하지 못했으나, 사용자 설치 후 2026-10-23에 Rust/Cargo 1.99.1을 확인했다. `cargo test --offline`의 위치 변환 테스트 4개와 `cargo clippy --offline --all-targets -- -D warnings`가 통과했다. `cargo fmt`로 포맷을 적용한 뒤 `cargo fmt --check`도 통과했다. 이후 `wasm32-unknown-unknown` 타깃 설치를 확인하고 `cargo build --offline --release --target wasm32-unknown-unknown`도 통과했다. 이 시점의 산출물은 위치 변환 기반 라이브러리였다.

이후 문단 문서 모델·선택·트랜잭션·undo/redo 코어를 구현하고 총 14개 테스트, Clippy, 포맷, WASM 빌드 통과를 확인했다. 이후 계속 구현 요청에 따라 WASM ABI v1, Markdown 파서·정규화·안전한 렌더러, 브라우저 편집기·표·붙여넣기·첨부·레이아웃과 임베딩 API를 추가했다. 현재 검증 범위와 남은 항목은 구현 계획·호환성 문서에 기록한다.

현재 로컬 검증: Rust 34개 테스트, 브라우저 29개 테스트, Clippy·포맷·WASM 릴리스 빌드 및 배포 패키징 통과. 별도 대상 브라우저·실제 모바일·OS IME 검증은 남아 있다.
