# 서재 / SOHJAE 네이밍 결정 기록

- 상태: 영문 이름 `SOHJAE` 선택. 세부 표기 스타일과 슬로건은 미확정.

## 결정 요약

한국어 이름은 **서재**, 선택한 영문 철자는 **SOHJAE**다. 사용자는 후보를 검토한 뒤 `SOHJAE`라고 명시적으로 선택했고, 이어 이 이름의 여러 언어권에서의 부정적 의미 가능성을 질문했다.

이름을 정한 대상은 **글쓰기 앱**이다. 한국어 ‘서재’가 가진 글쓰기 공간의 의미를 바탕으로, 영미권 사용자에게도 어색하지 않은 로마자 이름을 찾는 것이 목적이었다.

표준 표기를 그대로 따르는 것보다 읽기 쉬움과 브랜드 인상을 중요하게 고려했다. 다만 선택한 철자가 모든 언어권에서 한국어 ‘서재’와 같은 발음을 보장한다는 뜻은 아니다.

## 사용자가 밝힌 기준

1. 한국어 이름 ‘서재’를 바탕으로 한다.
2. 영미권 사용자에게도 어색하지 않은 표기를 찾는다.
3. `SEO`를 잘못 읽는 경우가 많다는 이유로 선호하지 않는다.
4. `SUHZAE`가 영미권에서 중국어처럼 보일 가능성을 우려한다.
5. 선택한 `SOHJAE`에 주요 언어권에서 이상하거나 부정적인 의미가 있는지 확인하고 싶어 한다.

## 후보와 검토 흐름

아래의 발음 및 인상 설명은 **당시 Gemini가 제시한 의견을 요약한 것**이다. 실제 사용자 조사나 언어별 검증 결과로 취급하지 않는다.

| 후보 | 대화에서의 검토 내용 | 결과 |
| --- | --- | --- |
| `SEO` / `SEOJAE` | Gemini는 표준 표기로 소개했다. 사용자는 `SEO`의 오독이 많아 싫다고 밝혔다. | 최종 선택하지 않음 |
| `SO` / `SUO` | ‘서’의 대체 표기로 시작했으나, Gemini는 각각 ‘소’, ‘수오’처럼 읽힐 가능성을 지적했다. | 초기 검토 |
| `SUOH` | 사용자가 추가로 제안했다. Gemini는 ‘수오’처럼 나뉘어 읽힐 수 있다고 설명했다. | 최종 선택하지 않음 |
| `SUH` / `SUHJAE` | Gemini가 발음 중심의 대안으로 반복 추천했다. | 유력 대안이었으나 최종 선택하지 않음 |
| `SOH` / `SOHJAE` | Gemini는 부드럽고 아늑한 시각적 인상과 글쓰기 앱의 분위기를 연결했다. | **사용자가 `SOHJAE` 선택** |
| `SUHZAE` | Gemini가 글로벌 브랜드 변형으로 제안했다. 사용자가 중국어처럼 보이지 않느냐고 질문했다. | 우려 제기 후 다른 후보 검토 |
| `SOHZAE` | 사용자가 추가로 제안했다. Gemini는 `HZ` 조합과 발음의 모호함을 이유로 `SOHJAE`를 추천했다. | 최종 선택하지 않음 |
| `SOJAE` / `SOJA` | Gemini가 더 짧고 간결한 대안으로 제안했다. | 최종 선택하지 않음 |

그 밖에 `SUR`, `SU`, `Suhja`, `Suhjaeo`, `Suhjae.app`, `SEOWRITE`, `SeoJae Write`, `The Seojae`, `Seojae Studio`, `Seojae Note`도 보조 대안이나 확장 예시로 언급되었으나 선택으로 이어지지 않았다.

## 선택을 뒷받침한 논의

사용자가 선택 이유를 별도의 문장으로 확정하지는 않았다. 다음은 선택 직전과 직후 Gemini가 제시한 근거이며, 네이밍 논의의 맥락으로 보존한다.

- **의미:** 한국어 ‘서재’를 통해 자신만의 공간에서 글을 쓰는 경험을 연결한다.
- **시각적 인상:** `SOH`의 글자 형태가 부드럽고 따뜻한 분위기에 어울린다는 제안이 있었다.
- **철자 구성:** `Z` 대신 `J`를 쓰고 `JAE`를 결합하는 방향이 제안되었다. 이는 사용자가 제기한 `SUHZAE`의 인상에 대한 우려에 대응한 것이다.
- **발음의 절충:** Gemini는 영어권에서 ‘소재’에 가까운 발음이 나올 수 있다고 설명했다. 한국어 발음의 완전한 재현보다 전체 이름의 읽기와 인상을 함께 고려한 흐름이었다.
- **확장 가능한 이야기:** 글쓰기의 ‘소재’를 연상시키는 중의적 이야기가 제안되었다. 이는 보조적인 브랜딩 아이디어이며, 이름의 기원이나 공식 슬로건으로 확정된 사항은 아니다.

## 표기 스타일과 브랜드 방향

확정된 것은 `SOHJAE`라는 **철자 선택**이다. Gemini는 표시 스타일로 `SohJae`와 `sohjae`를 추천했지만, 사용자가 어느 스타일을 최종 채택했는지는 원문에 없다.

현재 저장소는 README 제목 등에 `Sohjae`, 코드와 경로 등에 `sohjae`를 사용한다. 이는 기록 시점의 사용 현황이며, 대화에서 새로 확정한 대소문자 규칙은 아니다.

Gemini가 제안한 브랜드 분위기는 아늑함, 지적인 공간, 부드러움, 미니멀한 타이포그래피다. 대표 색상, 로고, 앱스토어 부제목, 슬로건은 이 대화에서 정하지 않았다. AI 글쓰기, 일기, 소설 집필 등 구체적인 기능·타깃 역시 질문과 예시로만 등장했으므로 확정 요구사항으로 보지 않는다.

## 다국어 검토에 대한 기록과 한계

사용자는 마지막으로 `SOHJAE`가 “세계 6대 언어”에서 이상한 의미를 가질 가능성을 물었다. Gemini는 이를 **UN 6개 공용어인 영어·스페인어·프랑스어·중국어·러시아어·아랍어**로 해석해 답했다.

| 언어권 | 당시 Gemini 답변의 요지 |
| --- | --- |
| 영어 | 부정적 의미가 없고 `JAE`가 친숙하게 느껴질 것이라고 평가 |
| 스페인어 | `H`와 `J`의 발음 차이로 원래 의도와 다른 발음이 나올 수 있다고 설명 |
| 프랑스어 | 부정적 의미가 없다고 평가하고, `Soie`와의 연상을 제안 |
| 중국어 | `JAE`가 한어병음 조합과 달라 중국 브랜드로 오해되지 않을 것이라고 평가 |
| 러시아어·아랍어 | 음차했을 때 금기어나 비속어와 연결되지 않는다고 평가 |
| 기타 유럽 언어권 | `J` 발음 차이와 `Soja`의 콩 의미를 보조적으로 언급 |

Gemini는 최종적으로 “100% 안전한 이름”이라고 단정했지만, 첨부 대화에는 이를 뒷받침하는 언어별 조사 자료나 원어민 검토가 없다. 따라서 이 문서는 **다국어 검증 완료 또는 안전성 보증을 기록하지 않는다.** 발음 예측, 특정 국가·언어처럼 보인다는 인상, 부정적 의미가 없다는 주장은 모두 당시 AI의 미검증 평가다. `J`로 바꾸면 특정 문화권의 인상이 “완전히 사라진다”는 단정도 같은 한계를 가진다.

이 기록 작업에서는 외부 사실 검증을 수행하지 않았다. 원문에 붙어 있는 검색 결과 제목과 일부 문구도 참고 흔적일 뿐, 실제 출처 내용을 확인한 근거로 사용하지 않았다.

## 남아 있는 확인 사항

- 브랜드 표시의 대소문자 규칙: `SOHJAE`, `Sohjae`, `SohJae`, `sohjae`의 용도 구분.
- 영문 발음 안내의 필요 여부와 실제 목표 사용자에게서의 읽기·인상 확인.
- 다국어 부정적 의미에 대한 별도 검토.
- 상표, 도메인, 앱스토어 및 기존 서비스와의 이름 중복 확인. 이 대화에는 조사 완료 근거가 없다.
- 슬로건, 부제목, 로고, 색상 등 후속 브랜드 요소.

이 항목들은 후속 확인 대상으로 남긴 것이며, 이미 선택한 `SOHJAE`를 취소하거나 새로운 후보를 결정한 것은 아니다.
